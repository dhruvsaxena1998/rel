# REL
The REL (Rule Expression Language) system is a domain-specific language compiler that translates human-readable conditional expressions into JSONLogic format. 

he system provides both command-line and HTTP API (`WIP`) interfaces for converting REL expressions like
`@age > 18 AND @name == 'John'` into structured JSONLogic objects that can be executed by rule engines.
